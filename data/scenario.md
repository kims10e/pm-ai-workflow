# 가상 시나리오: Aster Retail(가상) 레거시 DW → Databricks 마이그레이션

모든 회사·인물·수치는 가상이다.

- 고객: Aster Retail(가상), 국내 유통사. 온프레미스 레거시 DW와 야간 배치 ETL 운영.
- 목표(고객 OKR): O1 분석 플랫폼 현대화 — KR1 핵심 리포트 40종 Databricks 전환, KR2 야간 배치 완료 시간 6h → 3h, KR3 레거시 DW 라이선스 종료일 준수.
- 범위: 데이터 이관, ETL 파이프라인 전환, BI 리포트 재연결, 검증, 운영 이관. 제외: 신규 리포트 개발, 사용자 교육 전체(관리자 교육만 포함).
- 기간: 16주(가상). 웨이브 3회(파일럿 1 + 확장 2).
- 조직: 고객 PM, 데이터팀 리드, BI팀 리드 / 공급사 TPM(본인 역할), RSA 1, 데이터 엔지니어 2, 파트너 엔지니어 2.
- 거버넌스: 주간 현황 보고(금), 격주 운영위원회, 마일스톤마다 고객 리뷰.
