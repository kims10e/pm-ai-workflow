# 가상 SOW 요약 — Aster Retail DW Migration (가상)

1. 단계와 산출물
 - P1 착수(1주): 수행계획서, Charter, 공동 OKR 표
 - P2 분석·설계(3주): 현황조사 결과서, 마이그레이션 계획서(웨이브 포함), 테스트·검증 계획서
 - P3 수행(10주): 웨이브별 이관 결과서, 성능 비교 보고서, 주간 현황 보고서
 - P4 인수·이관(1주): 인수시험 결과서, 운영 절차서, 관리자 교육 자료
 - P5 종료(1주): 완료 보고서, Lessons Learned
2. 가정: 고객이 2주 안에 소스 DB 읽기 권한과 테스트 환경을 제공한다. BI 도구 버전은 변경하지 않는다.
3. 제외 범위: 신규 리포트 개발, 최종 사용자 교육, 레거시 DW 하드웨어 폐기.
4. 인수 조건: 요건 반영, 정상 가동, 이관 전후 리포트 수치 일치, 배치 성능 목표 충족.
5. 인도품목 검토: 고객은 10영업일 안에 검토 결과를 통보한다.
6. 변경 관리: 범위·일정·비용 변경은 Change Request로 승인한다.
