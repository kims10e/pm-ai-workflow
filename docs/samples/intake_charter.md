# Project Charter — Aster Retail(가상) 레거시 DW → Databricks 마이그레이션

- 상태: 확정 (PM 승인 2026-11-23)
- 근거: SOW 요약(data/sow_sample.md)과 시나리오(data/scenario.md). 모두 가상 데이터

## 1. 목적과 배경
- 목적: Aster Retail(가상)의 온프레미스 레거시 DW를 Databricks로 마이그레이션하여 분석 플랫폼을 현대화한다. 데이터 이관, ETL 파이프라인 전환, BI 리포트 재연결을 16주 안에 완료한다.
- 배경: Aster Retail(가상)은 온프레미스 레거시 DW와 야간 배치 ETL을 운영 중이며, 라이선스 종료 일정과 성능 한계로 인해 Databricks로의 전환이 필요하다. PM 표준 딜리버리 프로세스 P1~P5에 따라 착수한다.

## 2. 목표
- O1 분석 플랫폼 현대화: 핵심 리포트 40종 Databricks 전환, 야간 배치 완료 시간 단축(6h→3h), 레거시 DW 라이선스 종료일 준수

## 3. 범위
### 포함
- 데이터 이관
- ETL 파이프라인 전환
- BI 리포트 재연결
- 검증
- 운영 이관
- 관리자 교육 자료 작성·제공

### 제외
- 신규 리포트 개발
- 최종 사용자 교육
- 레거시 DW 하드웨어 폐기

## 4. 성공 기준
- 요건 반영
- 정상 가동
- 이관 전후 리포트 수치 일치
- 배치 성능 목표 충족
- 핵심 리포트 40종 Databricks 전환 완료
- 야간 배치 완료 시간 3h 이하
- 레거시 DW 라이선스 종료일(14주차) 준수

## 5. 가정과 제약
### 가정
- 고객이 2주 안에 소스 DB 읽기 권한을 제공한다
- 고객이 2주 안에 테스트 환경을 제공한다
- BI 도구 버전은 변경하지 않는다

### 제약
- 전체 수행 기간 16주(가상)
- 범위·일정·비용 변경은 Change Request로 승인한다
- BI 도구 버전 변경 불가

## 6. 조직과 역할
| 역할 | 책임 |
|---|---|
| 고객 PM | 고객 측 최종 의사결정 및 승인, 리소스 제공 조율 |
| 데이터팀 리드 | 소스 DB 접근 권한 제공 및 데이터 제공 협조 |
| BI팀 리드 | BI 리포트 재연결 검증 협조 |
| TPM(공급사) | 프로젝트 전체 관리, 일정·리스크·이슈 조율 |
| RSA | 솔루션 아키텍처 설계 및 성능 튜닝 |
| 데이터 엔지니어(2명) | ETL 파이프라인 전환 및 데이터 이관 수행 |
| 파트너 엔지니어(2명) | 확인 필요 |

- 범위·일정·비용 변경은 Change Request로 승인한다

## 10. PM 확인 사항
- 배치 성능 목표의 구체적인 수치 기준(목표 배치 완료 시간)이 SOW에 명시되지 않아 G1 합의 전 고객과 확인 필요
- 이관 전후 리포트 수치 일치의 허용 오차 또는 반올림 규칙이 SOW에 명시되지 않아 확인 필요
- "정상 가동" 인수 조건의 판단 기준(기간, 에러율 등)이 SOW에 명시되지 않아 확인 필요
- 고객 테스트 환경의 구체적 사양(DB 버전, 용량, 접근 경로 등)이 SOW에 명시되지 않아 확인 필요
- 웨이브 3회의 데이터 범위 분할 기준이 SOW에 명시되지 않아 마이그레이션 계획(M2) 수립 시 확인 필요
- 파트너 엔지니어(2명)의 구체적 역할 및 책임이 시나리오에 명시되지 않아 확인 필요
- 본 Charter 및 공동 OKR은 초안이며 PM 승인 후 고객 PM과 G1 합의(서명)를 거쳐야 확정된다
