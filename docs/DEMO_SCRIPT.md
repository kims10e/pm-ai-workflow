# 시연 영상 시나리오 (2분 45초)

가상 프로젝트의 8주차를 **텔레그램 메모 → AI 초안 → 사람 승인 → Workbook 반영**으로 한 바퀴 보여주는 영상입니다. 모든 데이터는 가상입니다. 소리 내어 읽을 문장만 따로 모은 파일은 [DEMO_NARRATION.md](DEMO_NARRATION.md)입니다.

## 전하려는 메시지 한 줄
**"AI는 변경을 제안하고, 사람이 승인해야만 반영된다. 모든 변경에는 근거가 남는다."**
(English: *The AI proposes; only a human approval applies the change, and every change keeps its evidence.*)

## 준비

| 구분 | 할 일 |
|---|---|

**시연용 메모**(텔레그램에 한 통으로 보냅니다. 첫 줄 `/memo 8`, 나머지는 줄바꿈으로 구분):

```
/memo 8
- 웨이브1 리포트 16종 중 9종 전환 완료, 파일럿 8종 포함 누적 17종 (진척 56%)
- 야간 배치 2.9h로 단축, 목표 3h 달성 확인
- 고난도 스토어드 프로시저 3건은 RSA가 담당, 전환 방안은 다음 주 확정
- BI 도구 버전 고정을 고객이 서면으로 재확인
- 다음 주: 웨이브1 잔여 7종 전환, 웨이브2 착수 준비
```

누적 합계를 메모에 직접 쓴 이유: "9종 완료"만 쓰면 AI가 합계를 계산할 수 없어 OKR 갱신을 보류합니다(스킬의 규칙). 시연에서는 OKR이 움직이는 장면이 보여야 합니다.

## 촬영 팁

- **처음부터 끝까지 한 번에 찍되 대기 구간(약 5분)만 편집으로 자릅니다.** 대기 중에는 화면을 건드리지 않아도 됩니다.
- 봇이 승인 요청을 보낸 뒤 **버튼을 누르기 전에 3초 멈춥니다.** 사람이 결정하는 순간이 영상의 핵심입니다.
- 승인 후 같은 버튼이 사라지는 것, 그리고 `approve --week 8 --root demo_run`을 한 번 더 실행하면 **"이미 확정됨"으로 막히는 것**(중복 승인 차단)을 20초 보너스 장면으로 넣을 수 있습니다.
- 시간이 남으면 [반려] 장면을 따로 찍어도 좋습니다. 반려하면 그 초안은 `approve`로도 승인되지 않습니다. 다시 찍으려면 `prepare_demo.ps1`을 실행하세요.

## 영상에 나오면 안 되는 것

- `.env` 파일, 봇 토큰, chat id (텔레그램 설정 화면과 터미널의 `.env` 출력도 포함)
- 사용자 이름이 보이는 경로(`C:\Users\<이름>\…`), 개인 이메일, 텔레그램 프로필 사진·계정 이름
- 실제 회사·고객 이름. 이 프로젝트의 데이터는 모두 가상이라 화면에 "(가상)" 표기가 보이면 충분합니다.

## 문제가 생겼을 때

| 상황 | 대응 |
|---|---|
| `claude` 호출이 실패하거나 너무 오래 걸림 | 텔레그램에서 `/memo 8 force`로 다시 보냅니다. 그래도 안 되면 `prepare_demo.ps1`로 초기화합니다. |
| 결과가 어색함(엉뚱한 변경, 근거 부족) | 숨기지 말고 **[반려]**를 눌러 "AI 제안은 사람이 거를 수 있다"는 장면으로 쓰거나, 초기화 후 다시 찍습니다. 실행마다 결과가 다릅니다. |
| 승인 요청에 버튼이 없음 | 변경이 너무 길어 텔레그램에 다 표시하지 못한 경우입니다(안전장치). 메모를 줄이거나 터미널에서 `approve --week 8 --root demo_run`으로 승인합니다. |
| 5분 대기를 줄이고 싶음 | **B안**: 촬영 전에 `python src/pm_agent.py run --week 8 --root demo_run`을 미리 실행해 두고, 촬영 때는 `python src/pm_agent.py request --week 8 --root demo_run`부터 보여줍니다. 메모 입력 장면은 빠집니다. |
